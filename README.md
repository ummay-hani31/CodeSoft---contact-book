# 📒 Contact Book

A simple **Contact Book application** built with Python.  
This project helps users store and manage contacts easily. Users can add, view, search, update, and delete contacts with input validation for phone number and email.

## 📌 Features

- ➕ Add new contacts
- 📋 View all saved contacts
- 🔍 Search contacts by name
- ✏️ Update contact details
- ❌ Delete contacts
- 📞 Phone number validation (must be exactly 10 digits)
- 📧 Email validation (must contain @ and .com)
- 💾 Save contacts for later use
- 🖥️ Easy command line interface

## 🛠️ Technologies Used

- Python 3
- Functions
- Lists / Dictionaries
- File handling / JSON
- Command Line Interface (CLI)
